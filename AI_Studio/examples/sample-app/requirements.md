# DemoShop — Requirements

## 1. Authentication
- REQ-1: A registered user shall be able to log in with email and password and reach their account page.
- REQ-2: Logging in with an incorrect password must show an error message and keep the user on the login page.
- REQ-3: The account page must not be accessible without logging in.
- REQ-4: A user shall be able to reset a forgotten password via an emailed link.

## 2. Catalogue
- REQ-5: Users can search products by name; only matching products are listed.
- REQ-6: A search with no matches shall tell the user that no products were found.

## 3. Cart
- REQ-7: Users can add a product to the cart from its detail page, and the cart page lists it with its price.
- REQ-8: The navigation shall always show the current number of items in the cart.

## 4. Non-functional
- REQ-9: Pages should load within 2 seconds on a typical connection.
