# Simplification audit: the runner and everything around it

Date: 2026-11-12. Scope: the local-runner work and the website, server, runner program and data that touch it. Base: main `7f4c175` plus the round-47 fixes (the ponytail audit). The audit read the code; nothing was changed by it.

## The model it was judged against

- **One runner per person** (decided 2026-11-11). A person sets it up once in **Settings, Your runner** and it is used for every run, schedule, recording and phone session they start. There is no runner picker. Schedules and deploy triggers run on their creator's runner. "Users can select compatible runners" means: a run goes to the person's own runner when it can run the test, and otherwise says plainly why.
- The website is the product. The runner is a light, headless program (Windows, macOS, Linux) that connects out to the platform. The platform is the source of truth for job state and never runs tests itself in `runners` mode (production).

## Deliberately kept

- **Security controls:** the runner switches (code scripts, private addresses, connected phone) and the code-scripts notice; one-time codes with expiry; machine binding; credential rotation; the single confirmation on "Remove this computer"; `authenticate` refusing team credentials; the owner checks (`ownerMayRun`, the Crowd4Test check before schedule and trigger runs); the private-address checks on server and runner; the server execution guard.
- **Reliability:** every update state (signed updates, rollback, manual), the sweep (accept timeout, one re-offer, lost runner), device reservations, the hand-over on restart, the result outbox, and the live run view rebuilt from stored events.
- **Compatibility:** the runner protocol (versions 1 and 2), hello's fields, `--token`, and the `/api/agent/*` shapes that installed runners use; the Windows and macOS installers.

## Deferred, with the reason

BE-4, BE-6, BE-11 and BE-14 change live data, the schema or the build, or need production numbers that the audit could not read. They are proposed, not done.
