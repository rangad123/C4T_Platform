## Exploring in runners mode (rounds 51 and 52)

With `EXECUTION_MODE=runners` the server still never opens a browser, and **exploring an application works**: the exploration
runs on the runner of the person who starts it, the AI staying on the platform. See [explore-on-runner.md](explore-on-runner.md).
Since round 52 these run on a runner the same way: explorations started by a schedule or a deploy trigger (on the runner of the
person who made the schedule or the trigger), tests described in words, and agent runs; and exploring a phone app (on the phone attached to
the runner) and security assessments (their checks sent from the runner). Still refused there, with a sentence: recordings "on the server".
