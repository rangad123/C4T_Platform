The action primitive — one coral primary per view, everything else secondary or ghost.

```jsx
<Button variant="primary" size="lg" iconRight="arrow-right">Book a demo</Button>
<Button variant="secondary">See the platform</Button>
<Button variant="inverse-ghost">Talk to us</Button>
```

Variants: `primary` (coral fill, the single conversion action), `secondary` (white + hairline outline), `ghost` (nav and toolbar use), `link` (inline), `inverse` / `inverse-ghost` (on `--surface-inverse` bands). Sizes 36/44/52px — use `lg` in heroes and CTA banners only.
