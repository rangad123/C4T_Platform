Renders a Lucide icon tinted with `currentColor` — the only icon primitive in the system; never hand-roll an SVG.

```jsx
<Icon name="shield-check" size={24} />
<Icon name="arrow-right" size={16} label="Continue" />
```

Names are Lucide kebab-case. Sizes: 16 inline with body text, 20 in buttons and nav, 24 in list rows, 32 in feature cards.
